Support

Install on iPhone

Open Zikr in Safari, tap Share, choose Add to Home Screen, then tap Add. Apple does not permit websites to trigger this installation automatically.

Install on Android

Use the Install Zikr button or open Chrome’s menu and choose Install app.

Protect your history

Create an encrypted backup regularly from Settings. Store the file and passphrase separately. Clearing site data or deleting the installed web app may remove local history.

Reminders

Install Zikr first. On iPhone, web push requires iOS 16.4 or later. Reminders also require the public deployment to have a push service configured.

Report a problem

Open an issue at github.com/faiqhilman13/zikr-app/issues. Do not attach private dhikr history or backup files.
